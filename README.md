# Русификатор Runehaven / Runehaven Russian Translation

Неофициальный русификатор Runehaven для Steam. Добавляет русский язык в интерфейс и игровые тексты Runehaven.

Русификатор переводит интерфейс, предметы, руны, подсказки, уведомления, записки, обучение и сценарные тексты. Перевод интерфейса выполняет BepInEx-плагин во время игры; файлы сценариев устанавливаются отдельным контентным модом.

## Скачать русификатор Runehaven

Готовая версия доступна в разделе [Releases](https://github.com/BrownCattail/Runehaven-Russian-UI/releases). Для установки скачайте архив `Runehaven_RU_x.x.x.zip` из последнего релиза.

## Что переведено

- интерфейс, меню и уведомления;
- предметы, руны и их описания;
- подсказки, обучение и взаимодействия;
- записки и сценарные игровые тексты.

## Установка

1. Полностью закройте Runehaven.
2. Установите BepInEx 6 для Unity IL2CPP в папку игры. Без него будет работать только контентный перевод, а интерфейс останется на английском.
3. Скачайте последнюю версию русификатора в разделе [Releases](https://github.com/BrownCattail/Runehaven-Russian-UI/releases) и распакуйте архив.
4. Запустите двойным щелчком `Install-Runehaven-RU.bat`.
5. Если игра не найдена автоматически, вставьте путь к папке Runehaven. Например: `E:\SteamLibrary\steamapps\common\Runehaven`.
6. Дождитесь сообщения об успешной установке и запустите игру.

## Содержимое репозитория

- `releases/Runehaven_RU_x.x.x.zip` — готовый пакет русификатора;
- `Install-Runehaven-RU.bat` — простой установщик для запуска двойным щелчком;
- `Install-Runehaven-RU.ps1` — установщик контентного мода и DLL;
- `translations.json` — переводы файлов сценариев;
- `src/RunehavenRussianUi` — исходный код UI-плагина.

## Совместимость

Русификатор подготовлен для версии Runehaven 1.1.2. После обновления игры отдельные строки могут потребовать обновления мода.

## Обратная связь

Если встретили английский текст, приложите скриншот и, по возможности, файл `BepInEx/config/RunehavenRussian.untranslated.txt`.
