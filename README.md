# Runehaven Russian UI

Неофициальный русификатор для Steam-версии Runehaven.

Проект переводит внутриигровый интерфейс, предметы, руны, подсказки, уведомления, записки и тексты обучения. Перевод интерфейса выполняет BepInEx-плагин во время игры; файлы сценариев устанавливаются отдельным контентным модом.

## Установка

1. Полностью закройте Runehaven.
2. Установите BepInEx 6 для Unity IL2CPP в папку игры. Без него будет работать только контентный перевод, а интерфейс останется на английском.
3. Скачайте и распакуйте архив из папки `releases`.
4. Запустите PowerShell в распакованной папке и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
& '.\Install-Runehaven-RU.ps1' -GamePath 'E:\SteamLibrary\steamapps\common\Runehaven'
```

Если игра расположена в другом месте, замените путь после `-GamePath`.

5. Запустите игру.

## Содержимое

- `releases/Runehaven_RU_0.1.11.zip` — готовый пакет русификатора;
- `Install-Runehaven-RU.ps1` — установщик контентного мода и DLL;
- `translations.json` — переводы файлов сценариев;
- `src/RunehavenRussianUi` — исходный код UI-плагина.

## Совместимость

Русификатор подготовлен для версии Runehaven 1.1.2. После обновления игры отдельные строки могут потребовать обновления мода.

## Обратная связь

Если встретили английский текст, приложите скриншот и, по возможности, файл `BepInEx/config/RunehavenRussian.untranslated.txt`.
